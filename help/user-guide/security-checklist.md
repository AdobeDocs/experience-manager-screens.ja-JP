# AEM Screens セキュリティチェックリスト {#security-checklist}

AEM Screens セキュリティチェックリストページでは、主要なセキュリティ領域に関する質問と検討事項のチェックリストが説明されています。

## チェックリストテーブル {#checklist-table}

| **セキュリティ領域** | **チェックリスト** | **はい／いいえ／NA** |
|---|---|---|
| **AEM および Screens のソフトウェアのアップデート** | **前***最新のAdobe Experience Manager（AEM）サービスパックは適用されていますか？* <br>**b.** *最新のAEM Screens機能パックは適用されていますか？* <br>**c.** *[AEM Screens Player Downloads](https://download.macromedia.com/screens/) から入手可能な最新のAEM Screens Player ソフトウェアを使用していますか？* | |
| **物理的セキュリティ** | **前***不要なポートをすべて無効にしましたか？* <br>**b.** *ケーブルとハードウェアのセキュリティを確保していますか？* <br>**c.** *該当する場合、コンテナを使用していますか？* | |
| **ネットワークセキュリティ** | **前***サイネージデバイスに分離サブネットを使用していますか？* <br>**b.** *分離されたサブネットは、AEM、Adobe Analytics、またはその他の必要なサービスなど、必要なエンドポイントへのアクセスを許可しますか？* <br>**c.** *企業のベストプラクティスを使用して Wi-Fi を保護しましたか？* <br>**d.** *同期再生を使用する場合、プライマリデバイスでのみ WebSocket の TCP 24503 を許可していますか？* <br>**e.** *許可されたデバイスのみがオーサリングインスタンスの登録サービスにアクセスできるように、プレーヤーデバイスの IP アドレスの範囲のブロックを解除しましたか？* | |
| **オペレーティングシステムのセキュリティ** | **前***オペレーティング システムを最新バージョンにアップグレードし、必要なセキュリティ パッチをすべて適用しましたか？* <br>**b.** *不要なサービスをすべて無効にし、不要なアプリケーションを削除しましたか？* <br>**c.** *エンタープライズポリシーを適用するために、デバイスをデバイス管理に登録しましたか？* <br>**d.** *デバイスを 1 つのアプリケーション（プレーヤー）のキオスクにロックしましたか？* <br>**e.** *OS のセキュリティ更新プログラムをインストールするための標準的な運用手順（SOP）を導入していますか？*<br>**f.***マルウェア対策ソフトウェア、管理者以外のユーザーなど、使用中のオペレーティングシステムのセキュリティのベストプラクティスに従ったことがありますか？* | |
| **アプリケーションセキュリティ** | **前***実稼動の管理 UI、チャネルスイッチャー、アクティビティ UI を無効にしましたか？* <br>**b.** *実稼動環境のログレベルは最小限に抑えられましたか？* <br>**c.** *AEMへの接続に https を使用していますか？* <br>**d.** *CA 署名証明書またはエンタープライズ PKI を使用していますか？ （自己署名証明書ではない）*<br>**例：***SSL v3 ではなく TLS を使用していますか？*<br>**f.** *登録時にデバイスとAEMの登録トークンを検証していますか？*<br> **g.** *使用中のデータを分類し、デバイスに PII または PHI が存在しないことを確認しましたか？*<br> **h.** *使用中のデータが分類されていて、デバイス上に個人を特定できる情報（PII）または保護された医療情報（PHI）が存在しないかどうか*<br> **一***監視メールを構成していますか？ 監視メールへの対応と非送信デバイスの処理に関する SOP が整備されているか。* | |
| **アクセス制御** | **前***役割ベースのアクセス制御（RBAC）を社内で識別および管理していますか？* <br>**b.** *Adobeのベストプラクティスを使用して、作成者、管理者、プレーヤーへのアクセスを提供する際に、最小権限の原則に従ったことがありますか？* | |
